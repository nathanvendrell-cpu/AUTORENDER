# Validation status — 0.5.0 source snapshot

This is a source release, not a notarized installer. Native behavior, data tests, simulated scale tests and human acceptance are separate checks.

The normal app and separate mixed UI harness compile and pass strict ad hoc signature verification. Source and packaged file hashes were checked. Data suites have producer results for catalogue, dashboard, scanner, fixture isolation and Python collection; these are not claims of native responsiveness.

A limited native session observed four known jobs in the compact All list, separate version counters, search for a work and its correct version detail. This does not establish all scenarios or accessibility compliance. Folder opening and file reveal in Finder, window detach/resize/minimize/reopen, persistence and loaded preview captures remain unverified in the independent session. No human acceptance is claimed.

The isolated harness provides synthetic static launch cases of 2, 3 and 50 jobs. The mixed 50 case contains ten video works, including one with ten versions, fifteen audio works and sixteen additional records. It generates only neutral temporary text files, not rendered audio/video. Native execution of the revised harness and dynamic job arrival in the same instance are not yet independently verified. Harness projection timings do not establish frame rate or production performance.

Actual configuration, catalogues, screenshots, logs, render files, private host details and credentials are intentionally excluded. Public examples are generic. No license has been added without an explicit licensing decision.
